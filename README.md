# EzeeStayy

Integrated Student Relocation Platform designed for university towns across India.

## Features
- **Hostel Finder & Verified Bed Booking**: Real-time room inventory, deposit tracking, and direct warden contact.
- **Door-to-Door Luggage Shipping**: Student luggage courier logistics.
- **Dorm Essentials Starter Packs**: Curated room packs (bedding, buckets, desk accessories) delivered before arrival.
- **Portals**:
  - Student Dashboard (`#/dashboard`)
  - Hostel Admin Portal (`#/hostel-dashboard`)
  - Platform Super Admin (`#/admin-dashboard`)

## Tech Stack
- **Frontend**: React, Vite, TailwindCSS, Lucide Icons, HashRouter
- **Backend**: FastAPI (Python), Motor (Async MongoDB), Pydantic
- **Database**: MongoDB Atlas
